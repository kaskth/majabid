# 🃏 مجابيد — لعبة ورق جماعية أونلاين (2 ضد 2)

> **ورق المجالس... كِل ولا تنكِل — الإصدار 1.4 «واجهة الجيل الجديد»**

> 📋 **الخطة الاستراتيجية الكاملة للمستقبل (حتى العالمية):** راجع [`ROADMAP.md`](./ROADMAP.md)

لعبة ورق شعبية مبنية على نظام **الأبراج والجمع الاستراتيجي** — فريقان (2×2) يتنافسان على بناء أبراج ورقية
وسرقة أكلة الخصوم عبر نظامي **«وقّف!» (الكمين)** و**الجبيد (قمة البرج)**، مبنيّة على القواعد الرسمية للعبة.

---

## 🎮 الإصدار 1.4 — واجهة الجيل الجديد + إصلاحات جوهرية
- **شهرة (مستوحى من تطبيق Play Store الحقيقي):** شاشة رئيسية بهيرو بطاقات،
  زر «لعب سريع» برتقالي كبير، شريط تنقل سفلي (الرئيسية/الجلسات/الصدارة/المظهر/القوانين)،
  لوح جلسات سفلي (بدء/انضمام/مشاهدة)، منصة تتويج في الصدارة، ومتجر مظاهر — كلها RTL كامل.
- **بطاقات SVG مرسومة يدوياً:** أرقام بنقاط حقيقية، آس بزخرفة، صور/ملوك/جاك بأزياء عربية،
  جوكر ذهبي — بلا أي صور خارجية.
- **أفاتارات مصوّرة 3D** (6 شخصيات PNG) بدل الرموز التعبيرية في كل مكان: المنتقي
  والمقاعد والردهة والصدارة وبطاقة الحساب — وبوتات تحملها أيضاً.
- **حركات حقيقية:** طيران البطاقات من اليد إلى الميدان، مروحة يد منحنية،
  توهّج وحلقة عدّ عند دورك، اهتزاز عند «وقّف!»، كنفيتي ونبض عند الفوز.
- **بوتات تفكر:** مؤجّل 700–1500ms قبل كل حركة + مؤشر «… يفكّر» على المقعد.
- **إصلاح «undefined»:** رتبة المقعد تُرسل دائماً كسلسلة ('' للضيوف) وتُعرض فقط إن وُجدت.
- **إصلاح اللعب على الجوال:** مروحة يد تعمل باللمس وأزرار إجراءات كبيرة.
- **أزرار فعّالة كلها:** انضمام بكود + روابط دعوة `?room=`، إعدادات الردهة (وضع/هدف/مظهر)
  تُبثّ فوراً، القوانين، الصدارة، الشات السريع، والنقر على المقاعد للحجز.

## 🎮 الإصدار 1.3 — حسابات فعلية + نظام تنافسي
- **حسابات كاملة:** تسجيل/دخول باسم مستخدم وكلمة مرور (تشفير Scrypt + جلسات توكن)،
  أو اللعب كضيف — والحساب يُسترجَع عند العودة من أي جهاز (توكن في localStorage).
- **نقطة تنافسية:** جولة الفرق: +12 للفائزين / −6 للخاسرين · فردي: +18/0/−6/−12 ·
  فوز المباراة: +40 · **الخروج الصريح أثناء اللعب: −30** (كما في اللعبة الأصلية).
- **رتب رمزية:** 🃏 مبتدئ → 🎯 متمرّس (100) → 🗡️ صيّاد (250) → 👑 مَجابِد (500) →
  🕌 شيخ الطاولة (1000) → 🌟 أسطورة (2000) — مع شريط تقدّم وشعار الرتبة فوق أسماء اللاعبين.
- **🏆 الصدارة العالمية:** لوحة أفضل 10 لاعبين بالنقاط التنافسية، + بطاقة لاعب
  (نقطة/مباريات/فوز/أفضل جولة/مواليد) وإشعار النقاط بعد كل جولة.
- **хранилище:** `users.json` (قابل للنقل إلى قاعدة بيانات لاحقاً).

## 🎮 الإصدار 1.2 — أوضاع لعب + مشاهدة مباشرة
- **🎯 وضع فردي ×4:** كل واحد لنفسه — يأكل من الجميع بلا شراكات ولا حماية،
  ألوان مقاعد مميزة (أزرق/أحمر/بنفسجي/فيروزي) ولوحة نتائج رباعية.
- **🏁 هدف الجلسة:** حتى 500/1000/2000 — أول فريق أو لاعب يبلغ الهدف
  يتوّج بطل المباراة 👑 (لافتة بطل + كونفيتي + زر «مباراة جديدة» يحسب من الصفر).
- **👁️ جلسات مباشرة + مشاهدة:** قائمة الجلسات النشطة في الرئيسية،
  انضم كمتفرج بأي وقت (بلا تحكم، بلا كشف أوراق) — أساس البث والبطولات القادمة.
- **🪑 3 مظاهر طاولات:** كلاسيكي أخضر / مجلس شعبي (سجادة حمراء مخططة) / ليلي ملكي (كحلي ذهبي).

## 🎮 الإصدار 1.1 — واجهة ألعاب احترافية + مؤثرات

- **بطاقات SVG فاخرة** (لا صور خارجية) — زوايا مزدوجة، جوكر ذهبي، ظهر منقوش.
- **محرك حركات:** تحليق البطاقات بمسارات منحنية (ميدان ↔ كومة ↔ يد)، انعكاس القلبات،
  ترتيب تسلسلي للأحداث (يتحرك ثم يُعرض صحيحاً) بلا تداخل.
- **محرك مؤثرات Canvas:** شرارات، حلقات، كونفيتي نهاية الجولة، وميض شاشة،
  إطار أحمر نابض في «الطور الختامي».
- **قائمة حسب الأحداث:** أصوات موضعية (ضع، كنس، كمين، جوكر) + اهتزاز مؤسسة `shake`.
- **تلميحات محسّنة:** لوحة أكل معلّقة فوق كومة المالك، لافتة «وقّف!» بعدّاد تنازلي،
  زر الكمين النابض، حلقة دور دوّارة + شريط وقت لكل مقعد.
- **تفاعلات:** جرس «نادِ شريكك»، فقاعات المحادثة فوق المقاعد، سجل شريطي حي.
- **استقرار:** كشف الانقطاعات القاسية وتحويل المقعد لبوت خلال 200ms،
  تنقية الغرف اليتيمة، إصلاح تكرار تسجيل الأحداث.

## ✨ ما تم تنفيذه

| المواصفة | التنفيذ |
|---|---|
| نظام 2 ضد 2 أونلاين | غرف WebSocket + كود دعوة + لعب سريع + بوتات تكمّل الناقص + إعادة اتصال تلقائية |
| مخزون 424 ورقة | 8 أطقم باصرة كاملة (8×52) + 8 جوكر — يُتحقق من حفظ عدد الورق في كل خطوة |
| بناء الأبراج | كل كومة = **جبيد** (المكشوف العلوي) + طبقة **مدفونة** (ورق مقفول) |
| نظام «الجبيد» | السرقة تعتمد على قمة البرج: طابقها بورقة بيدك → تكنس كل المكشوف + **الجوكرات المدفونة** |
| قوانين الجوكر | الكمين: الجوكر يأكل أي رقم، و«فيتو» يوقّف أي أكلة، لا يُرمى بالميدان أبداً ويُدفن دائماً |
| الحسبة المخفية | النقاط **لا تظهر أثناء اللعب** إطلاقاً — تنكشف في نهاية الجولة (10 للمشاريع، 50 للجوكر) مع لوحة تفصيلية |

## 🎮 قواعد اللعب المنفّذة (حسب القوانين الرسمية)

1. **الهدف:** أكثر نقاط في الكومة — العشرة والصور والإكّة = **10**، الجوكر = **50**، الباقي صفر.
2. **التوزيع:** الموزّع 13 والباقون 12، الميدان يفتح بـ13 ورقة (رتبة من كل نوع بلا جوكر)، اليد تتجدد إلى 13 عند دورك.
3. **الأكل:** انزل ورقة تطابق رقماً بالميدان أو بجبيد خصم → تكنس **كل المطابق** دفعة واحدة (الميدان + كومات الخصوم والشريكة). الأكل إجباري إذا كان كل ورقك يأكل.
4. **وقّف!** بعد كل أكلة نافذة **5 ثوانٍ** للجميع: من عنده نفس الرقم أو جوكر يخطف الأكلة — كل خطفة تعيد العدّ، وآخر من استقرت عنده يواصل دوره حتى يرمي.
5. **السرقة:** أخذ الجبيد **ومعه الجوكرات المدفونة** — المدفون المختلف يبقى لصاحبه.
6. **الجوكر:** لا يُرمى بالميدان، ولا يكون الجبيد، يُدفن دائماً.
7. **الطور الختامي** (نفاد الرزمة): اللاعب التالي فقط يحق له خطفة واحدة تحسم فوراً، والخاطف لا يلعب، واليد الفاضية تنتقز تلقائياً.
8. **إذا وقف الجميع:** تنقلب ورقة من الرزمة للميدان (الجوكر لا ينقلب) — وإذا خلت الرزمة تنتهي الجولة ويُهمَل ما تبقى بالميدان.
9. **المؤقتات:** 20 ثانية للدور — عند انتهائها تُلعب حركة قانونية تلقائياً.
10. **الجماعي:** الشريكة مقابلك، كومتها مفتوحة لك، ولا ترمِ ورقة تكشف جبيدها ما دام عندك بديل (حماية الشريكة).

## 🚀 التشغيل

```bash
npm install        # يعتمد فقط على: ws
npm start          # الخادم على المنفذ 3000
```

افتح المتصفح على `http://localhost:3000` — أنشئ طاولة أو انضم بكود أو «لعب سريع» (البوتات تكمّل الناقص).

### متغيرات البيئة (اختيارية)
| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | 3000 | منفذ الخادم |
| `TURN_MS` | 20000 | مهلة الدور |
| `STOP_MS` | 5000 | نافذة «وقّف!» |
| `FINAL_STOP_MS` | 4000 | نافذة الطور الختامي |
| `BOT_MIN` / `BOT_MAX` | 350 / 900 | زمن تفكير البوت بالملي ثانية |

## 🛡️ ملاحظات التصميم

- **العدالة:** الخادم وحده يملك الحقيقة؛ الواجهة لا تستلم إلا ما يراه اللاعب فعلياً (عدد أوراق الخصوم، لا قيمها؛ الجوكرات المدفونة غير مرئية؛ النقاط الجارية غير مرئية).
- **الانقطاع:** بوت يكمّل مكانك فوراً، وتسترجع مقعدك عند العودة (نفس المعرّف المحفوظ في متصفحك).
- **الاتساع:** طاولة بأي عدد من البشر (حتى 4) والبقية بوتات — «لعب سريع» يجمعك بطاولة انتظار قائمة.
- **الواجهة:** بطاقات SVG مرسومة برمجياً، أفاتارات PNG محلية، وصوتيات Web Audio — لا اعتماد على أي موارد خارجية.
